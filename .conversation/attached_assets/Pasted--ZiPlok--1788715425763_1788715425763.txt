Создай современный премиальный лендинг для студии запусков под названием ZiPlok.

ВАЖНО:
Сайт должен визуально максимально соответствовать референсу:
- темный минималистичный дизайн;
- черный фон;
- яркие фиолетовые акценты;
- стеклянные прозрачные ZIP-пакеты;
- эффект упаковки продукта;
- премиальный digital-стиль;
- много воздуха;
- тонкие фиолетовые линии;
- мягкие свечения;
- крупная жирная типографика;
- интерфейс должен выглядеть как дорогой продуктовый лендинг.

НЕ использовать стандартные шаблонные блоки.
НЕ делать дизайн похожим на обычный корпоративный сайт.
НЕ использовать кислотные цвета.
НЕ перегружать интерфейс анимациями.

==================================================
ТЕХНОЛОГИИ
==================================================

Используй:

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion для плавных анимаций
- Lucide React только там, где действительно нужны иконки

Сайт должен быть:
- полностью адаптивным;
- идеально выглядеть на desktop;
- хорошо работать на mobile;
- иметь плавный scroll;
- иметь плавные hover-анимации;
- иметь качественную типографику.

АНИМАЦИИ
==================================================

Использовать Framer Motion.

При появлении блоков:

opacity: 0 → 1

translateY:
30px → 0


ZIP-пакеты:

- очень медленно floating animation;
- небольшое вращение;
- легкое изменение позиции.

Карточки:

- плавный fade-in;
- hover слегка увеличивает элемент.

Фиолетовые рукописные элементы:

- появляются с небольшим delay.

Анимации должны быть дорогими и ненавязчивыми.

ZIP-ПАКЕТЫ
==================================================

Очень важно:

ZIP-пакеты являются ключевой частью дизайна.

Создай reusable component:

ZipPackage

Props:

- type
- image/content
- rotation
- size
- glow

Визуально пакет должен выглядеть:

- прозрачный пластик;
- realistic reflections;
- складки;
- прозрачные края;
- фиолетовая застежка;
- темные тени;
- glass effect.

Использовать CSS:
backdrop-filter
blur
градиенты
полупрозрачные borders

Если используются изображения ZIP-пакетов,
сделать PNG/WebP с прозрачным фоном.

- эксперт;
- продукт;
- идеи;
- контент;
- продажи;
- воронка;
- запуск.

Сайт должен выглядеть дорого, технологично,
минималистично и современно.

Не использовать:

- стандартные градиентные hero-блоки;
- огромные круглые карточки;
- стандартные SaaS иллюстрации;
- чрезмерное количество иконок;

- шаблонный UI.
